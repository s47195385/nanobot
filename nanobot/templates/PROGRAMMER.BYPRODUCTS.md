# Programmer Byproducts

- **Design note (1–2 pages max)**
  - Context, goal, constraints, chosen approach, alt considered, edge cases.
- **Task plan**
  - Steps, owners, expected tests, rollout/rollback.
- **Test plan snippet**
  - Targeted tests to add/run; data/fixtures needed; acceptance checks.
- **Change log**
  - Summary, risk, migration/ops steps, toggles.
- **Standup stub**
  - Yesterday / Today / Blockers / Risks (keep crisp).
