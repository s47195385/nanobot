# Task List (modular & granular)

- Keep tasks short, independent, and testable.
- Example layout:

```
- [ ] T1: Set up project skeleton
- [ ] T2: Define data model for requirements
- [ ] T3: Implement API endpoint for tasks
- [ ] T4: Add focused tests for tasks API
```

- Update statuses with `[ ]` (todo) / `[x]` (done) / `[-]` (blocked) / `[>]` (in-progress).
- The agent can read this file to guide execution; you control prioritization.
